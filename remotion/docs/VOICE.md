# Voiceover Pipeline

Adapted from the DoublesQueueMaster remotion project — same mechanism,
Likha-specific script and voice.

## How it works

1. **Generate per-scene lines** — `scripts/gen-vo.mjs` calls
   [edge-tts](https://pypi.org/project/edge-tts/) (free Microsoft neural
   TTS via Python). One MP3 per script line → `public/vo/<name>.mp3`.
2. **Measure + schedule** — `gen-vo.mjs` probes each MP3's duration
   (ffprobe) and writes `src/vo-manifest.json`. `src/voiceover.ts` turns
   per-scene `ANCHORS` into final cue frames: each line starts at its
   anchor *or* after the previous line ends (+8f pad), whichever is later.
   Lines can never overlap, even after re-generating audio.
3. **Play per scene** — `src/components/AdAudio.tsx` renders each line in
   a `<Sequence from={at}>` so narration starts on its frame exactly.
4. **Music bed** — `AdAudio` layers a procedural loop (`public/music/
   bed.wav`, generated by `scripts/gen-sfx.mjs`) ducked to ~13% volume with
   fade in/out. Drop a licensed track at `public/music/bed.mp3` and pass
   `musicFile` to replace it.
5. **SFX cues** — `<Sfx at={frame} file="…"/>` for transition accents
   (`whoosh`, `click`, `chime`, `tick`, `win`, `dink`), generated by
   `gen-sfx.mjs`.

Keep scene lines ≤ ~4s so they sit inside their scenes with breathing
room — the scheduler will clamp overlaps, but a line that lands mid-scene
is a missed sync.

## Setup

```bash
pip install edge-tts        # one time
npm run gen:vo              # public/vo/*.mp3
npm run gen:sfx             # public/sfx/*.wav + public/music/bed.wav
```

`VOICEOVER_ENABLED` in `src/voiceover.ts` gates audio — the generated
`public/vo/`, `public/sfx/`, `public/music/` files are already in the repo
so it defaults to on. Flip it off to cut a silent variant.

## Voice choice

Default: **`en-US-AndrewNeural`** @ `+8%` — the same voice as the DinkMatch
ads (DoublesQueueMaster): "warm, confident, authentic".

- PH-accented alternative: `en-PH-JamesNeural` (male) or
  `en-PH-RosaNeural` (female) — swap in if a more local read wins with the
  target audience
- List all: `python -m edge_tts --list-voices`

Change `VOICE` in `scripts/gen-vo.mjs`, adjust `RATE` for pacing.

## Pronunciation

"Likha" is **leek-HAH**, "ERP" is spelled out. TTS mangles the real
spellings, so `gen-vo.mjs` writes them phonetically — `"leek-hah"` and
spaced caps `"E R P"` (hyphens get slurred) — while on-screen copy keeps
the real brand spelling. The CTA reads the domain once as the brand:
`"Your business, built your way. Leek-hah, E R P, dot com."` at a slower
`+0%` rate so the name lands deliberately. Keep this trick for any script
line that says the brand aloud.

## Better than TTS

A real human read beats every neural voice for ads. Record ~20s on a phone
(quiet room, conversational pace — Taglish is on-brand) and either:

- drop one file per line into `public/vo/` under the same names, or
- drop a single full take as `public/vo/full.mp3` and pass it via the
  `voiceoverFile` prop / `<Audio>` instead of `VO_LINES`.

## Sound-off first

Ads must still land muted — bold on-screen copy carries the message
(captions, headlines). VO is a bonus layer, never the only carrier of the
hook.
